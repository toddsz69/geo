Website Biodata Siswa

Project pertama ini merupakan halaman biodata personal yang dibuat menggunakan HTML dan CSS murni, tanpa framework apapun. Tujuan project ini adalah untuk menguasai dasar-dasar pembuatan struktur halaman web serta styling menggunakan CSS. Halaman ini menampilkan identitas diri, foto profil, informasi kelas, dan keterangan lainnya dalam layout yang bersih dan rapi.
