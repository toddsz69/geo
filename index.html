02 — Tentang

Deskripsi Singkat

Saya adalah Geoffrey Jonathon Darmawan, siswa kelas XIA1 di Kolese Kanisius Jakarta. Di balik seragam putih abu-abu, saya menyimpan ketertarikan yang dalam pada spiritualitas Ignatian. Menurut saya, hal ini mengajarkan hal tentang refleksi dan pelayanan.

Selama semester genap ini, saya mendalami HTML untuk membangun struktur, CSS untuk menghadirkan keindahan visual, dan JavaScript untuk menciptakan interaksi. Cita-cita saya menjadi Pater Jesuit tidak menghalangi saya untuk menguasai teknologi; justru sebaliknya, teknologi bisa menjadi wahana pelayanan yang lebih luas bagi sesama.
